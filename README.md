# Task Management Project

## Overview
This is a Spring Boot based Task Management System designed to manage tasks with
role-based workflow transitions and secure authentication.

## Features
- JWT based Authentication & Authorization
- User and Role Management
- Task Management
- Workflow & Status Transitions
- Role-based Transaction Control
- File Attachments (Cloudinary)
- Secure REST APIs

## Technologies Used
- Java
- Spring Boot
- Spring Security
- JWT
- Hibernate / JPA
- Maven
- MySQL

## Project Structure
- Controller
- Service
- Repository
- Entity
- Security
- Enum

## How to Run
1. Configure database in `application.properties`
2. Run `TaskManagementprojectApplication.java`
3. Use Postman to test APIs
